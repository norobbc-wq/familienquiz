# Familienquiz / مسابقة العائلة

Mindestens 2 Spieler oder Teams. Jede richtige Antwort gibt 1 Punkt. Nach der Antwort wird die Lösung gezeigt. Die Fragen wiederholen sich innerhalb einer Partie nicht. Am Ende gewinnt die höchste Punktzahl; Gleichstand ist möglich.

لاعبان أو فريقان على الأقل. تمنح كل إجابة صحيحة نقطة. تظهر الإجابة الصحيحة بعد الاختيار. لا تتكرر الأسئلة في اللعبة الواحدة. يفوز صاحب أعلى مجموع، ويمكن التعادل.

## Starten / التشغيل

`index.html` öffnen. Keine Installation, kein Build. / افتح index.html. لا يلزم تثبيت.

GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root) → Save.
